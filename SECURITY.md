# Security Policy

## Reporting a vulnerability

Email **contact@codedvisiondesign.co.uk** with the subject line `SECURITY: <repo>` and include:

- The repository the issue affects
- A description of the vulnerability
- Steps to reproduce
- (Optional) Suggested remediation

We aim to acknowledge within 3 working days and provide a timeline for a fix within 10 working days. Please do not open public issues for security disclosures.

## Scope

This policy applies to every repository under the [Coded-Vision-Design](https://github.com/Coded-Vision-Design) organisation. Issues affecting third-party dependencies should be reported upstream first.

## Coordinated disclosure

We follow coordinated disclosure. We will credit reporters in the fix release notes if requested.
